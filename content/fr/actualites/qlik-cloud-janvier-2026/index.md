Voici les nouveautés Qlik Cloud de janvier 2026.

## Rapports Word et PowerPoint

Il est désormais possible de construire des rapports personnalisés aux formats Word et PowerPoint à partir des données d’une application.

Les modèles de rapports sont construits directement sous Word / PowerPoint grâce à un complément (=add-in), comme cela est déjà le cas aujourd’hui sous Excel.

Les rapports peuvent ensuite être diffusés par mail, déposés dans des dossiers SharePoint ou encore générés à la demande (c’est-à-dire directement par les utilisateurs en prenant en compte les sélections actives). A noter que les rapports pourront être générés en DOCX / PPTX ou PDF.

Ces deux add-in constituent une véritable amélioration du reporting dans le cloud, et réduisent considérablement l’effort de migration depuis Qlik Nprinting pour les utilisateurs de la version client-managed de Qlik Sense. Notez que la prochaine version de Qlik NPrinting embarquera un outil de migration des modèles de rapports Word / PowerPoint pour le cloud.

## Qlik Data Gateway – Direct Access 1.7.10

Notez que les versions 1.6.X ne sont plus supportées depuis juin 2025.

Notez également que Qlik Data Transfer sera déprécié au 1er trimestre 2026 et qu’il est fortement conseillé de le remplacer par Qlik Data Gateway.

## Recherche sémantique pour les jeux de données

Le bouton « Afficher plus de résultats », dans la barre de recherche de contenu, permet d’utiliser l’IA pour interpréter la recherche, même en plusieurs langues, et trouver des applications ou **des jeux de données**via leur nom ou leur description.

## Améliorations de la logique métier

Pour rappel, la logique métier permet de personnaliser la manière dont l’Insight Advisor interprète les données d’une application.

### Groupe d’éléments principaux

Lorsque le modèle logique personnalisé d’une application est activé, un nouvel élément principal doit systématiquement être ajouté à un groupe logique (dimension, mesure ou calendrier) pour être pris en compte dans les recherches en langage naturel. Désormais, cet ajout peut se faire directement au niveau de l’élément principal dans la zone « Groupe de modèle de logique ». 

#### Import de vocabulaire via Excel

L’ajout de synonymes au vocabulaire d’une application est simplifié grâce à la possibilité d’importer les termes via un fichier Excel, dont un modèle est téléchargeable directement via le module d’import.

## Suppression du rôle « Developer »

La suppression du rôle « Developer » est effective depuis le 26 janvier. Il convient désormais d’**ajouter les utilisateurs et les groupes concernés à un nouveau rôle personnalisé incluant l’autorisation « Gestion des clés API ».**

Notez que les clés API des utilisateurs qui ne disposent pas de cette autorisation sont désactivées, et donc la communication avec les applications/services tierces coupées.
