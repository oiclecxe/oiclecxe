Voici les nouveautés Qlik Sense SaaS de novembre 2025.

## Lignes sous formes de zones dans les graphiques combinés

Les lignes d’un graphique combiné peuvent désormais être affichées sous forme de zones, qui peuvent être empilées pour afficher la valeur totale.

## Unité de l’axe continu dans les graphiques en barres

Le mode « Continu » du graphique en barres offre la possibilité de définir l’unité de la largeur des barres de façon à ce qu’elle soit cohérente avec la dimension utilisée. Il est donc désormais possible de représenter des années, des mois, des semaines ou encore n’importe quelle valeur de type numérique.

## Désactivation des messages d’avertissements

Un paramètre permet de désactiver les messages d’avertissements (qui apparaissent lors de la modification d’un élément principal par exemple) sur l’ensemble du tenant.

Il peut ensuite être annulé via les paramètres du profil si besoin.

## Génération de miniatures de feuilles

Depuis les propriétés, il est désormais possible de générer automatiquement une miniature à partir d’une capture de la feuille.

Cette dernière sera directement ajoutée dans la bibliothèque multimédia de l’application pour être réutilisée si besoin.

## Qlik Data Gateway - Direct Access 1.7.9

### Configuration depuis la console

La version 1.7.9 de Qlik Data Gateway permet de spécifier les chemins (connecteur « File ») et les URL (connecteur « REST ») auxquels la passerelle peut accéder directement depuis la console d’administration.

#### Metrics Collector

On notera également la mise à disposition d’un agent, [à configurer via un fichier JSON](https://help.qlik.com/en-US/cloud-services/Subsystems/Hub/Content/Sense_Hub/Gateways/direct-access-gateway-troubleshooting.htm#Metrics), permettant de récupérer des métriques afin d’analyser l’activité liée à QDG (poids des données transmises, RAM utilisée, etc.).

Notez que les versions 1.6.X ne sont plus supportées depuis juin 2025.

Notez également que Qlik Data Transfer sera déprécié au 1er trimestre 2026 et qu’il est fortement conseillé de le remplacer par Qlik Data Gateway.

## Nouvel emplacement disponible en France

Le choix se porte désormais à 13 emplacements : Etats-Unis, Europe (France, Irlande, Allemagne, Angleterre ou Suède), Asie-Pacifique (Singapour, Australie, Japon ou Inde), Moyen-Orient, Israël et Brésil.

## Qlik Automate

### Exécutions simultanées d’une même automatisation

Une nouvelle option, au niveau des paramètres de chaque automatisation, permet d’autoriser le lancement de plusieurs exécutions simultanées.

A noter que le nombre maximum d’exécutions concurrentes autorisé sur le tenant dépend de l’abonnement souscrit.

#### Génération de rapports HTML

Le connecteur « Qlik Reporting » propose deux nouveaux blocs « Get HTML Report » et « Get HTML Report As Text » permettant de générer un rapport HTML à partir du template d’un rapport d’application Qlik Sense et, respectivement, de partager le fichier généré (emplacement cloud, mail, etc.) ou bien d’utiliser le texte dans un autre bloc.
